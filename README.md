# appQuiz

Aplicativo de quiz mobile construído com **React Native** e **Expo**, estruturado com separação de telas (`janelas`) e estilos (`css`).

## Estrutura do Projeto

- `App.js` e `index.js` — Ponto de entrada e configuração principal da aplicação.
- `app.json` — Configurações do projeto Expo.
- `package.json` e `package-lock.json` — Dependências e scripts do projeto.
- `css/estilo.js` — Definições de estilos visuais da interface.
- `img/` — Recursos de imagem utilizados no aplicativo.
- `janelas/` — Telas do fluxo do quiz:
  - `home.js` — Tela inicial.
  - `pergunta1.js` — Primeira pergunta.
  - `pergunta2.js` — Segunda pergunta.
- `AGENTS.md` — Diretrizes/instruções para agentes ou automações no repositório.
- `LICENSE` — Licença do projeto.
